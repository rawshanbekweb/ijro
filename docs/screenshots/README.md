# Тақдимот учун скриншотлар

Барча расмлар ҳақиқий иловадан (NestJS сервер + PostgreSQL + Vite клиент) олинган,
ичида **mock (намунавий) маълумотлар**: 7 та соҳа, 15 та бажарувчи, 2 та назоратчи,
28 та топшириқ (турли ҳолатларда), изоҳлар ва тарих. Ўлчам: 1440px кенглик, 2x (Retina).

## Қайта яратиш

`scripts/` ичидаги скриптлар: `seed-demo.mjs` (API орқали маълумот киритади, натижани
`seed-out.json`га ёзади), `seed-demo-extra.mjs`, `backdate.mjs` (муддат/тарих саналарини
ўтмишга суради, SQL чиқаради) ва `shots.mjs` (Playwright, `node shots.mjs <out-dir>`).

Эслатма: скриншотлар кейинги тузатишлардан (соҳа рейтинги ва фоизлар ҳақиқий
маълумотдан ҳисобланиши, тўлиқ таржима, мобил юқори панел) **олдин** олинган.
Ўша пайтда сервер боғлиқ объектларни (соҳа номи, бажарувчи/муаллиф/изоҳ муаллифи
исми) қайтармагани учун `shots.mjs` уларни API жавобига ўзи қўшиб берган; ҳозир
сервер уларни ўзи қайтаради.
